# 🎃 GhoulEats

Welcome to **GhoulEats**, a haunted yet delightful **frontend web app** created for the [**Dev.to Frontend Challenge (Halloween Edition)**](https://dev.to/challenges/frontend-2025-10-15). This project brings together design, motion, and storytelling to serve up a fully interactive    website infused with Halloween spirit.

> **Best viewed on desktop** - the eerie motions, animations, and effects truly come alive on larger screens.

![screenshot](https://github.com/dipanshu447/ghouleats/blob/main/.github/preview.gif)

---

##  The Concept

GhoulEats is a **spooky-themed restaurant website** that blends creepy charm with modern frontend design. It was built between **November 6–9**, crafted with focus and creativity over just a few days. Every section, from the glowing hero to the animated food menu is filled with details that make the Halloween vibe come to life.

The site captures the essence of a haunted dining experience through interactive elements, custom AI-generated characters, and motion-enhanced UI transitions.


## Built With

* **React.js**
* **Vite**
* **Framer Motion**
* **Tailwind CSS** 

## Features

* **Smooth Navigation Bar** - Stylish and responsive for easy movement between pages.
* **Halloween Theme** - A fully immersive spooky design throughout.
* **Menu Page** - Over 20 food items with working category filters.
* **Crew Section** - Showcases creepy yet fun AI-generated chef characters.
* **About Section** - Describes GhoulEats mysterious origins.
* **Join Us Page** - Form for joining the GhoulEats crew.
* **Events Page** - Themed events with spooky card designs.
* **Framer Animations** - Soft motion effects for section entry and hover states.

## Pages Overview

* **Home Page:** Hero banner, about preview, and crew highlights.
* **About Page:** Story-driven description of GhoulEats’ theme and idea.
* **Menu Page:** Interactive menu with 20+ food items and category filters.
* **Join Us Page:** A form for aspiring chefs, waiters, or staff.
* **Events Page:** Showcases upcoming haunted events.

## What I Learned

Building **GhoulEats** taught me a lot about frontend design and development. I learned how to:

* Combine **motion and UI** for storytelling.
* Manage animations using **Framer Motion**.
* Use **AI-generated content** effectively to enhance the theme.
* Handle **component structure and reusability** in a large React project.

## How to Run

Clone the repository and run the project locally using Vite.

```bash
git clone https://github.com/dipanshu447/ghouleats.git
cd ghouleats
npm install
npm run dev
```
